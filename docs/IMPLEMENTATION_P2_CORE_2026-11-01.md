# P2 — نواة ملفات متطلبات الشراء: 01/11/2026

**الحالة: تنفيذ أولي منفصل، وليس اكتمال P2.** لا تغيير في واجهة GTK أو فحص L1 أو نظام حفظ USB في هذا التغيير.

## النطاق المنفذ في المصدر

- وحدة inspector/p2_profiles.py تتحقق من صيغة مستقلة profile_schema_version=1.
- رفض الحقول غير المعروفة والأرقام غير المنتهية وNaN وInfinity والتكرار في JSON والملفات الأكبر من 64 KiB.
- ملف المتطلبات اختياري؛ profile=None يعيد mode=general وpersonal_verdict=not_applied ويبقي الحكم العام دون تعديل.
- محرك تقييم read-only بخمسة محاور: technical_safety، hardware_requirements، workload_fit، seller_claims، economics.
- سعر البائع والضمان معلومات مدخلة تصريحيا عبر offer، وليست قياسات تلقائية.
- إخفاق SMART أو do_not_buy العام حائل لا يلغيه السعر المنخفض أو اختيار ملف متطلبات آخر.
- غياب معلومات RAM والقرص أو الملاءمة يعطي needs_verification؛ لا افتراض لصحة المكونات ولا FPS أو Benchmark مختلق.
- دعم متطلبات: RAM المثبتة من DMI، المعالجات المنطقية، سعة التخزين الاسمية، SSD، مجالات العمل P1، الميزانية DZD، الضمان، مطابقة وصف البائع للموديل وRAM.
- اختبارات مستقلة داخل tests/test_p2_profiles.py، دون الوصول إلى أجهزة فعلية.

## سياسة استقلالية النتائج

ترجع evaluate_purchase_profile نتائج شخصية منفصلة مع generic_verdict المنقول من التقرير كما هو؛ لا تعدّل report أو health_assessment أو purchase_assessment أو ملفات SHA-256. هذا المحرك لا يفتح ملفا ولا يحفظه على القرص من تلقاء نفسه.

## مثال لملف اختياري

~~~json
{
  "profile_schema_version": 1,
  "name": "برمجة وتصفح",
  "workloads": ["office", "light_programming"],
  "requirements": {
    "min_ram_gb": 8,
    "min_logical_processors": 4,
    "min_storage_gb": 256,
    "require_ssd": true
  },
  "max_price_dzd": 65000,
  "min_warranty_months": 6
}
~~~

## المتبقي قبل اكتمال P2

1. محرر/مستورد/مصدّر GTK عربي RTL مع اختيار ملف عام أو مخصص.
2. إدخال عرض البائع والسعر والضمان من المستخدم، مع حفظ مصدرهما التصريحي.
3. عرض الحكم الشخصي في GTK وHTML دون المساس بالتقرير الخام أو التوافق مع الملفات القديمة.
4. الحفظ الآمن للملفات الشخصية في وجهة مصرّح بها فقط، وليس أقراص الجهاز الداخلية.
5. اختبارات CI ثم اختبار واجهة ميداني، ومقارنة أجهزة مختلفة بالملف نفسه.

**حد القبول:** نجاح اختبار النواة لا يعني إتاحة اختيار الملف داخل ISO أو استكمال مرحلة P2.
