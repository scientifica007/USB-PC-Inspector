# P0 — الجرد الموسع والأدلة الزمنية: التنفيذ البرمجي الأول

**التاريخ:** 30/10/2026  
**المرجع:** [PR #4](https://github.com/scientifica007/USB-PC-Inspector/pull/4)  
**الإصدار المصدر:** `0.1.5-beta.1` — **غير معتمد ميدانيًا بعد**.  
**النسخة المثبتة ميدانيًا قبل هذا التغيير:** `0.1.4-beta.1` على HP 630 في BIOS Legacy / Ventoy.

## ما أُضيف فعلًا

1. `inspector/hardware_evidence.py`: جرد قراءة فقط من sysfs للرسوميات PCI (`class 0x03`)، وموصلات DRM وحالتها والأوضاع المعلنة وEDID (أسبوع/سنة عند صلاحية قيمة EDID)، وواجهات الشبكة الفيزيائية ونوعها إن أمكن. يمكن `lspci -D -nn` لتفسير أسماء GPU، وهو أمر قراءة فقط ومهلة 2 ثانية؛ إذا تعذر يبقى PCI ID من sysfs.
2. `age_evidence`: تاريخ BIOS موسوم **firmware_date**؛ ساعات تشغيل كل قرص SMART موسومة **powered_hours**؛ معلومات تاريخ لوحة العرض الموسومة **edid_panel_date** إن توفرت. **لا يوجد حقل لعمر الحاسوب مستنتج من هذه العناصر**.
3. `inspector/core.py`: حقلان اختياريان جديدان `hardware_extensions` و`age_evidence`، وتظهر `hardware_extensions` في لقطة التقدم بعد جرد التخزين. لا قرار شراء مبكر؛ يُجمع دليل ساعات التشغيل بعد فحص SMART.
4. `inspector/ui_model.py` و`gtk_gui.py`: تبويب **المكونات والعمر**، لا يخفي مجهولًا أو يصنف قطعًا «سليمة» لأنها مكتشفة.
5. `inspector/report.py`: أقسام إضافية لتفاصيل GPU والشاشات والشبكات والأدلة الزمنية، كلها مع تهريب HTML.
6. اختبارات `tests/test_hardware_evidence.py` تستخدم `TemporaryDirectory` لمحاكاة sysfs وEDID والشبكات، وتختبر عدم نشر MAC وعدم تخمين صحة GPU أو العمر، ومحتوى HTML.

## السلامة والتوافق

- لم تُعدل `usb_store` ولا `report_writer` ولا `complete.json` ولا طريقة التعامل مع USB/الأقراص الداخلية.
- يعتمد الجمع الجديد على معلومات عامة محلية عبر `sysfs` وأمر `lspci` اختياري متاح في حزمة ISO الحالية `pciutils`. لا استدعاء لأوامر فحص كتابة أو mount أو اختبار ضغط.
- لا تُنشر MAC أو SSID أو serial أو EDID bytes في تقرير الجرد الجديد.
- لا يتغير `schema_version=1` مع إضافة حقول اختيارية؛ البيانات القديمة تظل قابلة للقراءة على مستوى الواجهة والتقرير.
- تاريخ BIOS ليس تاريخ تصنيع الجهاز، وساعات تشغيل الأقراص ليست عمر الجهاز. حالة `not_tested` لا تعني الصحة.
- قراءة PCI/DRM/الشبكات قد تغيب بسبب تعريفات أو صلاحيات؛ التقرير يعرض الغياب بوضوح دون اختلاق عتاد.
- لم يجرِ دمج الهاتف أو ملف الشراء أو محرك الصحة/الملاءمة في هذه النسخة؛ تلك مراحل لاحقة مستقلة.

## التحقق والمعايير

- **اختبارات Python وGTK: PASS** على PR #4 في GitHub Actions [run 41072702113](https://github.com/scientifica007/USB-PC-Inspector/actions/runs/41072702113).
- **المطلوب قبل الاعتماد الميداني:** نجاح بناء ISO الجديد، ثم فحص L1 واحد على HP 630 للتأكد من التوقيت والرسوميات والشاشة والشبكة، وساعات القرص، وإمكان حفظ/استرجاع تقرير جديد من `PCINSPDATA`، دون إعادة اختبار B المزدوج.
- **لا تُعتبر اختبارات D أو G أو UEFI أو الإقلاع دون قرص منفذة** نتيجة اختبارات P0.

## المراحل التالية

1. **P1**: تقييم الحالة الصحية من الأدلة المتاحة، ومحرك نوعي للملاءمة لكل استخدام، ونتائج `undetermined` عند نقص GPU أو الاختبارات، دون نسب صحة وهمية.
2. **P2**: ملف متطلبات شراء محرر ومتحقق منه، يحافظ على الاستقلال بين الحالة التقنية والسعر والملاءمة.
3. **P3**: نقل للهاتف عبر شبكة Wi-Fi محلية/USB tethering مع اقتران آمن وmanifest وبصمات، ثم Bluetooth عند الدعم.
