# USB-PC-Inspector — خطة التطوير والتحقق

## v0.1 — المنفذ في المستودع

- [x] جرد أولي للـ BIOS والمعالج والذاكرة والبطارية ووحدات التخزين.
- [x] عدم اشتراط وجود قرص داخلي لتشغيل نظام Live.
- [x] تحليل SMART مع تصنيف حالة نقص البيانات.
- [x] واجهة عربية أولية وتقارير JSON وHTML.
- [x] حفظ تقارير على قسم USB مُتحقق منه، دون كتابة على القرص الداخلي.
- [x] إعداد بناء Debian Live ISO (UEFI وBIOS) واختبارات Python آلية.
- [ ] اختبار نجاح بناء ISO.
- [ ] فحص إقلاع UEFI وLegacy BIOS على أجهزة حقيقية.

- [ ] التأكد ميدانياً من حفظ التقارير على Ventoy.

## v0.2 — بعد فحص الأجهزة الحقيقية

- [ ] اختبار إرشادي للشاشة ولوحة المفاتيح والمنافذ.
- [ ] إدماج Memtest86+ كخيار إقلاع مستقل إن أمكن.
- [ ] اختبار SMART قصير اختياري بإذن مالك الجهاز.
- [ ] تحسين قراءة مستشعرات الحرارة ودعم العربية.

## v0.3 — التطوير المتقدم

- [ ] اختبارات أداء حرارية مضبوطة وبموافقة صريحة.
- [ ] مقارنة حاسوبين مع السعر وملاءمتهما للبرمجة وUbuntu.
- [ ] تقارير تفصل بين مفحوص وناجح وفاشل وغير مدعوم.

## ثوابت السلامة

1. لا كتابة على الأقراص الداخلية ولا تغيير لإعدادات Firmware.
2. البيانات الغائبة ليست علامة سلامة.
3. لا فحوص إجهاد أو فحوص كتابة افتراضياً.
4. قراءة إصدار BIOS لا تعني إثبات نزاهة برمجياته.
5. حفظ التقارير على USB يتم بأمر صريح من المستخدم.
