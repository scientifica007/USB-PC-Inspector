## M1 — فحص شراء عام سريع (أولوية P0)

- [ ] فصل collectors وdiagnostic rules وreport models وواجهة المستخدم.
- [x] تفسير smartctl exit bitmask والتمييز بين الإخفاق الحالي وسجلات الأخطاء السابقة، مع حفظ حقول تشخيصية مختارة في JSON واختبارات وحدات مكتوبة. **متبقٍ:** التحقق من تشغيل الاختبارات على CI، وتغطية السجلات التفصيلية والاختبار الذاتي القديم والتحقق الميداني؛ لا يُحفظ كامل JSON الخام مراعاةً للخصوصية.
- [x] بدء الفحص عند فتح الواجهة، وبث جرد BIOS/CPU ثم RAM والبطارية والأقراص وSMART عبر JSONL وعرضه تدريجيًا. **تنفيذ برمجي يحتاج تحققًا ميدانيًا**؛ لا يصدر حكم الشراء إلا مع التقرير النهائي.
- [x] حالات قرار L1 الأربع في الشيفرة والواجهة: مرشح مبدئيًا (بأدلة كافية محدودة)، افحص قبل الدفع، لا يُنصح، غير محسوم. **لم يُثبت تنفيذها الميداني أو نجاح CI بعد**؛ ليست شهادة سلامة أو تقييم سعر.
- [ ] الفصل بين اكتمال الفحص والتقييم الفني؛ عدم استنتاج سلامة من غياب بيانات.
- [x] **GTK 3 وPango RTL في تجربة HP 630 (28/10/2026):** صور Live لـ0.1.2-beta.1 تثبت تشكيل العربية واتجاهها في الملخص وتبويب JSON المقروء؛ تبقى تحسينات الفراغ العلوي وحجم نص الأدلة ومراجعة تواريخ العرض ضمن التحسينات، ولا تعني اكتمال دعم كافة الدقات.
- [ ] قياس زمن L1 بعد الإقلاع على أجهزة متنوعة (هدف أولي 10–30 ثانية، قابل للتعديل). أُضيفت أزمنة المراحل وزمن الفحص من بدء عملية الجمع؛ **لا تشمل زمن إقلاع USB** ولا تثبت الهدف الزمني.

**قبول M1:** إقلاع الجهاز، فحص عام دون ملف إعدادات أو إنترنت، نتيجة موثقة قابلة للحفظ، بلا طرفية وبلا كتابة على الأقراص الداخلية.

## ثوابت السلامة

1. لا كتابة على الأقراص الداخلية أو تغيير firmware.
2. لا تُعامل البيانات الناقصة على أنها سلامة أو عطل مؤكد.
3. لا اختبارات ضغط/فحوص طويلة أو كتابة افتراضيًا.
4. ساعات تشغيل القرص ليست إثباتًا لعمر الجهاز أو كونه جديدًا.
5. لا يُشترط تحضير منزلي، هاتف، إنترنت، أو AI.
6. لا يمتلك الهاتف أو الوكيل وصولًا عامًا إلى shell أو root.
7. لا يُدّعى نجاح نقل تقرير أو حفظه دون تحقق.
